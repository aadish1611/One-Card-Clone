# One-Card-Clone
A responsive and visually appealing frontend clone of the OneCard website, built using HTML and Tailwind CSS. This project replicates the look and feel of OneCard's landing page to demonstrate modern UI techniques with utility-first styling.

Features
Clean and modern design inspired by OneCard
Built entirely with Tailwind CSS (no custom CSS)
Lightweight and easy to customize

technology Used
HTML– semantic and accessible markup

Tailwind CSS – utility-first CSS framework for rapid UI development
